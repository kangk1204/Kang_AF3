# AlphaFold 3 라이선스·약관 정리 (가이드 삽입용)

작성 근거: 클론한 AF3 저장소(commit 97d2023, 2026-08-14)에 포함된
`LICENSE`, `WEIGHTS_TERMS_OF_USE.md`, `OUTPUT_TERMS_OF_USE.md`,
`WEIGHTS_PROHIBITED_USE_POLICY.md` 원문. 아래는 요약이며 법률 자문이 아니다.
최종 판단은 원문과 소속 기관 기술이전/법무 부서를 통해 확인해야 한다.
(약관 원문 최종수정일: 2024-11-09)

## 1. 세 가지 층으로 나뉘어 있다

| 대상 | 적용 문서 | 성격 |
|---|---|---|
| 소스 코드 | `LICENSE` (Apache 2.0) | 상업적 사용까지 허용 |
| 모델 가중치(af3.bin) | `WEIGHTS_TERMS_OF_USE.md` + `WEIGHTS_PROHIBITED_USE_POLICY.md` | 비영리 기관 한정, 재배포 금지 |
| 예측 결과물(구조·신뢰도 등) | `OUTPUT_TERMS_OF_USE.md` | 비영리 한정, 공개는 가능하나 고지·인용 의무 |

코드는 Apache 2.0이지만 가중치와 출력물은 별도 약관이 걸린다는 점이 핵심이다.
코드 라이선스가 느슨하다고 해서 가중치·결과물까지 자유로운 것이 아니다.

## 2. 가중치(Model Parameters) 약관 요점

- **비영리 기관에 의한, 또는 비영리 기관을 위한 비상업적 용도로만** 사용 가능하다.
  비영리 기관의 예로 대학, 비영리 단체·연구소, 교육기관, 언론, 정부 기관이 명시돼 있다.
- **상업적 활동에는 쓸 수 없다.** 여기에는 "영리 기업을 위해 수행하는 연구"도 명시적으로
  포함된다. 즉 위탁·공동연구 형태로 기업 과제를 수행하면 해당되지 않는다.
- **가중치 자체를 공개·공유하면 안 된다.** 예외는 약관 범위 안에서 같은 기관 내부 공유뿐이다.
  → af3.bin 파일을 GitHub, 공개 스토리지, 논문 보충자료에 올리는 것은 금지다.
  → 랩 내부 공용 스토리지에 두고 랩 구성원이 쓰는 것은 허용 범위로 읽힌다.
- 구글은 접근·사용 검증을 위해 이름·소속 등 추가 정보를 요구할 수 있고,
  약관 위반이 의심되면 사용 권리를 철회할 수 있다.
- 금지 용도 정책(Prohibited Use Policy)이 약관에 참조로 편입돼 있어 함께 적용된다.

### 실무 주의: 우리가 받은 가중치의 경로
`https://storage.googleapis.com/alphafold3/af3.bin.zst` 는 공개 URL이지만,
약관은 가중치를 "구글로부터 직접 받은 경우에만" 쓸 수 있다고 규정한다.
저장소 문서와 Dockerfile 주석 모두 접근 요청 절차
(https://github.com/google-deepmind/alphafold3)를 따르라고 안내한다.
**연구자 소속이 비영리 기관인지 확인하고, 가능하면 공식 요청 절차를 통해 접근 승인을
받아 두는 것이 안전하다.** 상업 조직 소속이거나 기업 과제 수행이면 이 경로는 쓸 수 없다.

## 3. 출력물(Output) 약관 요점

- 출력물의 소유권을 구글이 주장하지는 않는다("original Output"에 대해 소유권 미주장).
  다만 동일·유사 출력이 다른 사용자에게도 생성될 수 있음은 인정해야 한다.
- 그러나 **사용은 비상업 한정**이다. 영리 조직과 출력물을 공유할 수 없다.
  단 **과학 논문 게재, 오픈소스 공개, 저널리즘 목적 공개는 허용**되며,
  그 결과 간접적으로 기업이 접근하게 되는 것은 문제되지 않는다.
- **출력물로 AF3와 유사한 생체분자 구조예측 ML 모델을 학습시키는 것은 금지**된다.
  증류(distillation) 등 우회 방법도 금지에 포함된다.
  → 예측 구조를 라벨로 써서 자체 폴딩·도킹 모델을 학습시키는 계획은 약관 위반이다.
  → 스크리닝 결과로 결합력 예측 모델을 만드는 경우, "구조예측 모델"과의 경계를
    사전에 확인하는 것이 좋다.
- **공개·배포 시 고지 의무**: 출력물이 이 약관 하에 제공된다는 사실과, 내가 가한 수정
  내용을 눈에 띄게(conspicuous) 고지해야 한다. 약관 표기가 제거된 상태로 배포할 경우
  Output Terms of Use 사본과 함께 `Legally Binding Terms of Use` 텍스트 파일을 첨부해야 하며,
  그 파일에는 출력물 이용이 Output Terms of Use에 따른다는 문구와, 가중치는 구글로부터
  직접 받은 경우에만 사용 가능하고 Weights Terms of Use가 적용된다는 문구가 들어가야 한다.
- 약관과 충돌하는 추가·상이한 조건을 붙여 배포할 수 없다.

## 4. 인용 의무 (필수)

출력물을 배포하거나 AF3 사용으로 얻은 결과를 공개할 때 **아래 논문 인용은 의무**다.
고지 의무와 별개로 추가되는 요건이라고 약관에 명시돼 있다.

> Abramson, J. et al. Accurate structure prediction of biomolecular interactions
> with AlphaFold 3. *Nature* (2024). https://doi.org/10.1038/s41586-024-07487-w

부수적으로 함께 인용할 것을 권장하는 항목:
- 유전 데이터베이스 검색을 썼다면 HMMER (jackhmmer/nhmmer, Eddy lab, hmmer.org)
- 사용한 서열 DB (UniRef90, MGnify, BFD, UniProt, PDB, Rfam, RNAcentral, NT 등)
- 본 벤치마크의 테스트 서열은 UniProtKB에서 받았으므로 UniProt Consortium 인용

## 5. 이 프로젝트 상황에 대한 체크리스트

- [ ] 연구자 소속이 비영리 기관인가? (대학/국책연구소 등) → 아니면 가중치 사용 불가
- [ ] 이 2000건 스크리닝이 기업 과제·기업 위탁 연구의 일부인가? → 그렇다면 사용 불가
- [ ] 예측 결과를 자체 구조예측/폴딩 모델 학습 데이터로 쓸 계획이 있는가? → 금지
- [ ] af3.bin 을 랩 외부(공개 저장소, 협력 기업)로 전달할 계획이 없는가? → 전달 금지
- [ ] 결과 공개(논문·발표·특허 명세)시 Abramson et al. 2024 인용을 넣었는가?
- [ ] 결과물 공개 시 Output Terms 고지와 수정 내역 고지를 포함했는가?
- [ ] 가중치 공식 접근 요청 절차를 진행해 승인 기록을 남겼는가?

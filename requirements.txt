# 그림이 필요하면 이 한 줄만 하면 된다:
#     python3 -m pip install -r requirements.txt
#
# 주의: AF3 를 돌리는 conda 환경(예: ~/miniforge3/envs/af3) 안에는 설치하지 마라.
#       matplotlib 이 numpy 를 함께 끌어오므로 jax/CUDA 로 고정된 추론 환경의
#       numpy 버전이 움직일 수 있다. 그림은 AF3 와 무관한 후처리이므로 분리해라:
#           python3 -m venv ~/af3_plot_env
#           ~/af3_plot_env/bin/pip install -r requirements.txt
#           ~/af3_plot_env/bin/python scripts/af3_visualize.py <출력폴더> -o 그림
#       (검증 호스트에서 이 방식으로 matplotlib 3.11.1 설치 후 그림 생성을 확인했다)
#
# 그림 없이 표(CSV)만 쓸 것이면 아무것도 설치하지 않아도 된다:
#     python3 scripts/af3_visualize.py <출력폴더> -o 그림 --no-plot
#
# 이 목록은 스크립트 6개의 import 문을 전수 조사해서 만들었다 (근거: AST 파싱).
# 조사 결과는 docs/dependencies_notes.md 에 스크립트별로 정리돼 있다.
